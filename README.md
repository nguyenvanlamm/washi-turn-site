# Washi Turn site

Landing, support and privacy pages for Washi Turn (iOS puzzle game), served by GitHub Pages from `main`:
https://nguyenvanlamm.github.io/washi-turn-site/

Static HTML, no build step and no workflow (`.nojekyll`: files are served as-is). Game repo: nguyenvanlamm/washi-turn (private).

`index.html.md`, `support.html.md`, `privacy.html.md` and `llms.txt` mirror the pages for AI agents: update them
whenever page copy changes. `og-image.png` (1200x630) and `board-kraft-1.*` come from a real game capture.
